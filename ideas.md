# Portfolio Design Ideas — Jacob LeCoq

## Chosen Design: "Terminal Noir"

**Design Movement:** Brutalist Minimalism meets Developer Aesthetic (Linear/Vercel-inspired)

**Core Principles:**
1. Dark-first, high-contrast — every element earns its place
2. Asymmetric layouts — left-weighted, editorial, never centered-grid
3. Cyan as a signal color — used sparingly but powerfully for CTAs, highlights, and active states
4. Typography does the heavy lifting — large, confident headings; small, precise body text

**Color Philosophy:**
- Background: #0a0a0f (near-black with a blue-violet undertone)
- Surface: #111118 (cards, nav)
- Border: rgba(255,255,255,0.08)
- Accent: #22d3ee (cyan-400) — electric, technical, memorable
- Accent glow: rgba(34,211,238,0.15) for hover states
- Text primary: #f1f5f9 (slate-100)
- Text muted: #64748b (slate-500)

**Layout Paradigm:**
- Single-page with smooth scroll sections
- Left-aligned hero with large display type
- Projects in a masonry/asymmetric card grid
- Skills in a horizontal tag-cloud with category grouping
- Blog in a 2-col editorial layout
- Resume as a timeline with company logos

**Signature Elements:**
1. Subtle dot-grid background texture on the hero
2. Glowing cyan underline on active nav items
3. Code-style decorators (e.g., `// section`) before section headings

**Interaction Philosophy:**
- Hover states reveal depth (glow, border brightening)
- Scroll-triggered entrance animations (fade + slide up)
- Typewriter effect on hero subtitle

**Animation:**
- Hero: typewriter on tagline, fade-in on name
- Sections: staggered fade-up on scroll
- Cards: border glow on hover, subtle scale
- Nav: underline slide animation

**Typography System:**
- Display: Space Grotesk (700/800) — geometric, technical
- Body: Inter (400/500) — clean, readable
- Mono: JetBrains Mono — for code snippets and decorators
